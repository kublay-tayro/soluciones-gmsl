# Guía de Configuración Supabase

Para que la página funcione con el backend, necesitas seguir estos 2 pasos:

## 1. Crear el archivo de configuración

Crea un archivo llamado `.env.local` en la carpeta raíz del proyecto (`soluciones-gmsl/`) y pega el siguiente contenido. Reemplaza los valores con los que te de Supabase:

```env
VITE_SUPABASE_URL=https://tu-proyecto.supabase.co
VITE_SUPABASE_ANON_KEY=tu-clave-anonima-publica
```

## 2. Crear la Base de Datos

Ve al **SQL Editor** en tu panel de Supabase y ejecuta este código para crear la tabla de productos e insertar los datos de ejemplo:

```sql
-- Crear tabla de productos
create table products (
  id bigint generated by default as identity primary key,
  name text not null,
  category text not null,
  price decimal(10,2) not null,
  original_price decimal(10,2),
  image text not null,
  description text,
  badge text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
```
